# Week 1

## Roadmap notes

**What does a DevOps engineer do day to day?**
A DevOps engineer keeps software releases and systems running smoothly. Day to day, they automate testing and deployments, manage cloud infrastructure, monitor performance, and fix failures. They also work with developers to make releases faster, safer and more reliable.

**Which areas do I already know from infrastructure work?**
- Operating systems
- Networking and protocols
- Servers, firewalls and load balancers
- Cloud infrastructure and availability

**Which areas are newest to me?**
- Git/GitOps
- CI/CD
- Containers/Kubernetes
- Scripting and programming
- Infrastructure as code
- Monitoring and logs
